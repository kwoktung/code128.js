# code128.js 1.x

This page covers **1.x** (last release: `1.0.3`) and how to upgrade. 1.x is superseded by 2.0; see the [README](../README.md) for current usage.

## usage

1.x is a browser-only library that draws Code128 barcodes on an HTML5 canvas.

```js
import Code128 from 'code128.js'

var code = new Code128('code128')
code.insert(document.body)
```

Or with a `<script>` tag:

```html
<!DOCTYPE html>
<html>
  <body>
    <script src="/path/to/code128.js"></script>
    <script>
      (function() {
        var code = new Code128('code128')
        code.insert(document.body)
      })();
    </script>
  </body>
</html>
```

## api

`new Code128(input)` encodes `input` and throws `Input Required` when it is empty.

- `elements`: the encoded symbols, as rows of the internal symbol table (`[value, codeA, codeB, codeC, widths, bits]`).
- `insert(target = document.body)`: appends a `<canvas>` to `target` and returns it. It takes no options. Each module is drawn 1px wide and the barcode is 50px tall, with black bars and white spaces. The canvas is three times as wide as the barcode, and the extra area on the right is transparent.

Supported input is printable ASCII except `{` and `}`. Those two, and any other unsupported character, fail with a `TypeError`.

## migrating to 2.x

2.0 replaces the `Code128` class with functions and per-renderer imports.

| 1.x | 2.x |
| --- | --- |
| `new Code128(x).insert(el)` | `render(x, dom(el), { unitWidth: 1 })` |
| `new Code128(x).insert()` | `render(x, dom(document.body), { unitWidth: 1 })` (the target is required) |
| `new Code128(x).elements` | `encode(x).codes` (symbol values) and `encode(x).bits` (module string) |
| `<script>`: `new Code128(x)` | `<script>`: `Code128.render(x, Code128.dom(el))` (`window.Code128` is now a namespace) |

`render` comes from `code128.js` and `dom` comes from `code128.js/dom`.

Behavior changes:

- **`dom()` appends an inline `<svg>`, not a `<canvas>`.** To keep drawing on a canvas, size it with `layout` and draw with `canvas(ctx)`; see "canvas" in the README.
- **The default module width is `2px`.** In 1.x it was 1px. Pass `unitWidth: 1` to keep the old size.
- **The element is exactly as wide as the barcode.** There is no extra transparent area. Use `quietZone` to add margins.
- **Spaces are drawn by a background rect**, `'#fff'` by default. Pass `background: null` for a transparent background.
- **`{` and `}` now encode**, and other unsupported characters throw a descriptive error such as `Unsupported character "中" at index 2`.
- **Barcodes encode the same content but are often narrower.** 2.x switches between code sets A, B and C to find the shortest encoding. Inputs with runs of digits shrink: for example, `ABC123456` goes from 134 to 112 modules. Scanners read the same text, but the bars differ from 1.x, so update any snapshots or fixed-width layouts.

2.x also adds `svg()` and `canvas(ctx)` renderers, React Native support, layout options (`height`, `color`, `background`, `quietZone`), and custom renderers.
